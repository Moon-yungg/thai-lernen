# Prüfliste für eine Thai-Lehrkraft

Alle Thai-Inhalte der App wurden mit KI erstellt und anschließend von einer KI gegengeprüft. Geprüft wurden Schreibweise, Umschrift, Töne (zusätzlich maschinell mit PyThaiNLP), Übersetzungen und Grammatik. **Von einer Muttersprachlerin oder einem Muttersprachler geprüft wurde noch nichts.**

Die Dateien in diesem Ordner sammeln die Stellen, bei denen die Prüfung unsicher war. Wenn du eine Thai-Lehrkraft oder eine Tandempartnerin hast, gehe am besten diese Listen mit ihr durch. Sie enthalten vor allem:

- Töne von Lehnwörtern (z.B. คอมพิวเตอร์, มอเตอร์ไซค์, ซิมการ์ด)
- gesprochene Abweichungen von der Schrift (ไหม → mái, เขา → káo, ได้/ไม้/น้ำ lang oder kurz)
- natürliche Formulierungen (ob ein Satz so im Alltag gesagt wird)
- Höflichkeit und Register (ครับ/ค่ะ, จ้ะ, Umgangssprache)

**Hinweis zur Umschrift:** Die App verwendet ein einheitliches, vereinfachtes Schema. Es ist im Kopf von `src/data/types.ts` beschrieben. Jede Silbe trägt ihren gesprochenen Ton: à tief, â fallend, á hoch, ǎ steigend, ohne Zeichen mittel.
